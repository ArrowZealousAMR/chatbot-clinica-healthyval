# Chatbot Clínica HealthyVal

Plugin de WordPress para un chatbot guiado, multilingüe y configurable para clínicas.

## Funciones actuales

- Idiomas: castellano, valenciano e inglés
- Nombre opcional del usuario
- Menú guiado por categorías
- Información de tratamientos
- Horarios de atención
- Ubicación de la clínica
- Llamada telefónica
- WhatsApp
- Correo electrónico
- Redes sociales
- Enlaces directos a Google Maps
- Navegación sencilla mediante botones
- Diseño responsive para móvil, tablet y escritorio

## Tecnologías

- PHP 8.1+
- JavaScript (Vanilla JS)
- CSS3
- HTML5
- WordPress 6.5+
